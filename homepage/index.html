One gate. Many signals.

AgentProof does not replace tests, linters, scanners, or review. It connects them around one question: can this AI-generated PR be trusted enough to merge?

Verification scripts

Runs available test, build, lint, typecheck, Python, Go, Rust, and custom commands when configured.

Security smells

Flags committed env files, token-shaped secrets, hardcoded credentials, eval, and unsafe HTML surfaces.

AI slop

Catches lorem ipsum, coming soon copy, vague promises, fake testimonials, TODOs, and unfinished docs.

UI hygiene

Finds missing alt text, empty buttons, dead hash links, and weak accessibility basics.

Claim audit

Compares the final agent message against observed evidence so "tests passed" cannot be decorative.

Policy packs

Start relaxed for prototypes, strict for client delivery, or security-sensitive for auth and billing changes.

Receipts

Writes portable JSON evidence that reviewers can inspect or verify later.

GitHub native

Outputs SARIF, badges, PR comments, HTML reports, and a reusable `runstudio/agentproof@v1` action.
