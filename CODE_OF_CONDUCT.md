# Code of Conduct

AgentProof is built for maintainers who want safer, more reviewable AI-assisted code.

The project should be direct, practical, and welcoming without becoming vague or performative.

## Expected behavior

Contributors and maintainers are expected to:

- be respectful and specific;
- assume good intent, but ask for evidence;
- criticize ideas, code, claims, and tradeoffs without attacking people;
- keep security reports and private information out of public issues;
- help newcomers produce useful bug reports, rule requests, and examples;
- stay honest about what AgentProof can and cannot prove.

## Unacceptable behavior

The following is not acceptable:

- harassment, threats, insults, or personal attacks;
- publishing private code, tokens, secrets, logs, or customer data;
- repeatedly derailing issues with unrelated debates;
- demanding unpaid support as if maintainers were on-call;
- using the project to shame specific people, maintainers, or agent vendors;
- knowingly submitting misleading claims, fake evidence, or unsafe examples without labeling them.

## Project tone

AgentProof can be skeptical of unsupported claims without being hostile to AI tools.

Preferred framing:

```text
Agents are useful. Useful tools still need receipts.
```

Avoid turning issues into broad AI flamewars. Keep discussions grounded in examples, evidence, and reviewer value.

## Reporting problems

If the problem is a bug, open an issue using the bug template.

If the problem involves security, secrets, command execution, supply chain behavior, or private artifacts, do not open a public issue. Follow `SECURITY.md`.

If the problem involves contributor behavior, contact the maintainers privately when a private channel exists. If no private channel exists yet, open a minimal public issue that asks for maintainer contact without sharing sensitive details.

## Enforcement

Maintainers may:

- ask for edits to comments or issues;
- hide or delete harmful content where GitHub allows it;
- close derailed or unsafe discussions;
- block users who repeatedly violate these expectations;
- move sensitive reports out of public threads.

The goal is not to police tone aggressively. The goal is to keep AgentProof useful, safe, and evidence-based.
